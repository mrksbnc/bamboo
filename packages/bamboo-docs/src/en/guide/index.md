# Guide

The guide covers the decisions that sit around the components: installation, application structure, layout, spacing, color, accessibility, responsive behavior, and verification.

## Start here

1. [Getting Started](./getting-started) installs Bamboo and mounts the styles and Vue plugin.
2. [Layout and Spacing](./layout-and-spacing) explains padding, gaps, widths, and responsive containers.
3. [Color and Theming](./color-and-theming) documents semantic colors, token overrides, dark mode, and custom colors.
4. [Accessibility](./accessibility) gives the keyboard, focus, naming, and live-region rules used throughout the library.
5. [Responsive Composition](./responsive-composition) shows how to compose primitives into resilient application layouts.
6. [Testing and Quality](./testing-and-quality) turns the local checks into a repeatable release checklist.

## Design principle

Bamboo provides behavior and visual primitives, not a replacement for product structure. Keep semantic HTML, content hierarchy, and user intent in your application; use component props and slots to express those decisions consistently.
