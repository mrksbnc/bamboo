# Alert Dialog

`bo-alert-dialog` presents a blocking confirmation step. It teleports an alert dialog to `body`, focuses the panel when opened, and locks page scrolling while it is visible.

## Basic Usage

Use `v-model:open` to control visibility. The component closes itself before emitting `confirm` or `cancel`.

<ExampleFrame :code="basicExample">
  <bo-button @click="open = true">Delete project</bo-button>
  <bo-alert-dialog
    v-model:open="open"
    title="Delete project?"
    description="This action cannot be undone."
    variant="destructive"
  >
    <bo-text font-size="sm" variant="secondary">
      The project and its data will be permanently removed.
    </bo-text>
  </bo-alert-dialog>
</ExampleFrame>

<ExampleFrame :code="defaultExample">
  <bo-button variant="outline" @click="defaultOpen = true">Continue setup</bo-button>
  <bo-alert-dialog
    v-model:open="defaultOpen"
    title="Continue setup?"
    description="You can change these settings later."
    :show-cancel="false"
    confirm-text="Continue"
  />
</ExampleFrame>

## Variants and Actions

`variant="default"` renders a primary confirm action. `variant="destructive"` renders a destructive confirm action. Set `show-cancel` to `false` when cancellation is not needed and customize the button labels with `confirm-text` and `cancel-text`.

Escape closes the dialog only when `close-on-escape` is `true`; it defaults to `false` so a deliberate action is not accidentally dismissed.

## Accessibility

The panel uses `role="alertdialog"`, `aria-modal="true"`, and derives labelled and described references from `title` and `description`. Provide `aria-label`, `aria-labelledby`, or `aria-describedby` when you supply equivalent custom content. The close button uses `close-aria-label`.

## API Reference

### Props

| Prop              | Type                         | Default       | Description                                     |
| ----------------- | ---------------------------- | ------------- | ----------------------------------------------- |
| `id`              | `string`                     | Autogenerated | The id of the dialog panel.                     |
| `dataTestId`      | `string`                     | Autogenerated | The test id of the dialog panel.                |
| `open`            | `boolean`                    | `false`       | The visibility state, used with `v-model:open`. |
| `title`           | `string`                     | -             | The title in the dialog header.                 |
| `description`     | `string`                     | -             | Descriptive text below the header.              |
| `confirmText`     | `string`                     | `Continue`    | The confirm button label.                       |
| `cancelText`      | `string`                     | `Cancel`      | The cancel button label.                        |
| `showCancel`      | `boolean`                    | `true`        | Whether to render the cancel button.            |
| `variant`         | `'default' \| 'destructive'` | `default`     | The confirm action style.                       |
| `closeOnEscape`   | `boolean`                    | `false`       | Whether Escape cancels the dialog.              |
| `closeAriaLabel`  | `string`                     | `Close`       | Accessible label for the close button.          |
| `role`            | `HTMLAttributes['role']`     | `alertdialog` | The ARIA role of the panel.                     |
| `ariaLabel`       | `string`                     | -             | Accessible name when no title is used.          |
| `ariaLabelledBy`  | `string`                     | -             | Id of the element that labels the panel.        |
| `ariaDescribedBy` | `string`                     | -             | Id of the element that describes the panel.     |

### Events

| Event     | Payload | Description                                |
| --------- | ------- | ------------------------------------------ |
| `confirm` | -       | Emitted when the confirm action is chosen. |
| `cancel`  | -       | Emitted when cancel or close is chosen.    |
| `close`   | -       | Emitted after either action closes it.     |

### Slots

| Name      | Description                                  |
| --------- | -------------------------------------------- |
| `default` | Main dialog content.                         |
| `header`  | Custom header content in place of the title. |
