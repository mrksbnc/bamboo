# Input OTP

`bo-input-otp` renders one input per character, filters input with `pattern`, moves focus between cells, and accepts a complete value from paste.

## Basic Usage

Use `v-model` for the complete string. The `complete` event fires when the value reaches `length`.

<ExampleFrame :code="basicExample">
  <div>
    <bo-input-otp
      v-model="code"
      :length="6"
      label="Verification code"
      hint="Enter the code sent to your email."
      @complete="code = $event"
    />
    <p class="mt-2 text-sm text-neutral-500">Value: {{ code || 'Waiting for code' }}</p>
  </div>
</ExampleFrame>

## Input Behavior

The default configuration has `length="6"`, `type="text"`, `input-mode="numeric"`, and `pattern="[0-9]"`. Arrow keys move between cells, Backspace moves to the previous empty cell, and paste fills consecutive cells. Use `type="password"` to hide entered characters.

`disabled`, `read-only`, `required`, `autofocus`, `description`, `error`, and `hint` control common form states. Error text is preferred over description and hint when more than one is supplied.

## Accessibility

The group defaults to `role="group"` and labels each cell as a digit of the one-time password. Provide `aria-label` or `aria-labelledby` when the visible label is not sufficient.

## API Reference

### Props

| Prop              | Type                               | Default       | Description                               |
| ----------------- | ---------------------------------- | ------------- | ----------------------------------------- |
| `id`              | `string`                           | Autogenerated | Id prefix for the control and cells.      |
| `dataTestId`      | `string`                           | Autogenerated | Test id prefix for the control and cells. |
| `modelValue`      | `string`                           | `''`          | Complete value used by `v-model`.         |
| `length`          | `number`                           | `6`           | Number of character cells.                |
| `type`            | `'text' \| 'password'`             | `text`        | Whether characters are hidden.            |
| `pattern`         | `string`                           | `[0-9]`       | Pattern used to accept each character.    |
| `inputMode`       | `InputHTMLAttributes['inputmode']` | `numeric`     | Virtual keyboard hint.                    |
| `name`            | `string`                           | -             | Form name on the first cell.              |
| `label`           | `string`                           | -             | Visible group label.                      |
| `description`     | `string`                           | -             | Supporting text.                          |
| `error`           | `string`                           | -             | Error text and invalid state.             |
| `hint`            | `string`                           | -             | Hint text when no error or description.   |
| `required`        | `boolean`                          | `false`       | Marks the control as required.            |
| `disabled`        | `boolean`                          | `false`       | Disables every cell.                      |
| `readOnly`        | `boolean`                          | `false`       | Prevents editing while retaining focus.   |
| `autofocus`       | `boolean`                          | `false`       | Focuses the first cell on mount.          |
| `role`            | `HTMLAttributes['role']`           | `group`       | ARIA role for the cell group.             |
| `ariaLabel`       | `string`                           | -             | Accessible group name.                    |
| `ariaLabelledBy`  | `string`                           | -             | External label id.                        |
| `ariaDescribedBy` | `string`                           | -             | External description id.                  |

### Events

| Event               | Payload      | Description                             |
| ------------------- | ------------ | --------------------------------------- |
| `update:modelValue` | `string`     | Emitted as cells change.                |
| `complete`          | `string`     | Emitted when all cells contain a value. |
| `focus`             | -            | Emitted when a cell receives focus.     |
| `blur`              | `FocusEvent` | Emitted when a cell loses focus.        |
