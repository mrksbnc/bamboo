# Separator

`bo-separator` marks a boundary between content. It is decorative by default, so it is hidden from assistive technology unless you set `decorative="false"`.

## Horizontal Separator

<ExampleFrame :code="basicExample">
  <div class="grid gap-3"><span>Section one</span><bo-separator /><span>Section two</span></div>
</ExampleFrame>

## Orientation and Label

`orientation` accepts `horizontal` and `vertical`. A `label` places visible text at the center of the separator.

<ExampleFrame :code="labeledExample">
  <div class="flex items-center gap-4"><span>Navigation</span><bo-separator orientation="vertical" label="or" /><span>Settings</span></div>
</ExampleFrame>

## API Reference

| Prop          | Type                         | Default       | Description                                    |
| ------------- | ---------------------------- | ------------- | ---------------------------------------------- |
| `id`          | `string`                     | Autogenerated | Element id.                                    |
| `dataTestId`  | `string`                     | Autogenerated | Test id.                                       |
| `orientation` | `'horizontal' \| 'vertical'` | `horizontal`  | Separator direction.                           |
| `decorative`  | `boolean`                    | `true`        | Hides the separator from assistive technology. |
| `label`       | `string`                     | -             | Visible centered label.                        |
| `role`        | `HTMLAttributes['role']`     | -             | Optional ARIA role.                            |
| `ariaLabel`   | `string`                     | -             | Accessible label.                              |
