# Switch

`bo-switch` renders a button with `role="switch"` and an `aria-checked` state. Use `v-model` for its boolean value.

## Basic Usage

<ExampleFrame :code="basicExample">
  <div><bo-switch v-model="enabled" label="Email notifications" description="Receive project updates by email." /><p class="mt-2 text-sm text-neutral-500">{{ enabled ? 'Enabled' : 'Disabled' }}</p></div>
</ExampleFrame>

## Sizes and Orientation

`size` accepts `sm`, `default`, and `lg`. The label group is horizontal by default and can be changed to `vertical` with `orientation`.

<ExampleFrame :code="statesExample">
  <div class="grid gap-3"><bo-switch label="Disabled" disabled /><bo-switch label="Large switch" size="lg" orientation="vertical" /><bo-switch v-model="enabled" label="Required setting" required /></div>
</ExampleFrame>

## API Reference

| Prop                                               | Type                         | Default       | Description                        |
| -------------------------------------------------- | ---------------------------- | ------------- | ---------------------------------- |
| `id` / `dataTestId`                                | `string`                     | Autogenerated | Control id and test id.            |
| `modelValue`                                       | `boolean`                    | `false`       | State used by `v-model`.           |
| `size`                                             | `'sm' \| 'default' \| 'lg'`  | `default`     | Switch size.                       |
| `orientation`                                      | `'horizontal' \| 'vertical'` | `horizontal`  | Label layout.                      |
| `label` / `description`                            | `string`                     | -             | Visible text.                      |
| `disabled` / `required`                            | `boolean`                    | `false`       | Native button/form states.         |
| `name` / `value`                                   | `string`                     | -             | Form attributes.                   |
| `role`                                             | `HTMLAttributes['role']`     | `switch`      | Control role.                      |
| `ariaLabel` / `ariaLabelledBy` / `ariaDescribedBy` | `string`                     | -             | Accessible naming and description. |

The default slot adds content beside the label and description. The component emits `update:modelValue`.
