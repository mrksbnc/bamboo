# Progress

`bo-progress` displays a determinate value as a percentage of `max`. Values below zero and above the maximum are visually clamped to the 0-100 range.

## Basic Usage

<ExampleFrame :code="basicExample">
  <bo-progress :value="65" label="Uploading" show-value />
</ExampleFrame>

## Variants and Sizes

<ExampleFrame :code="variantsExample">
  <div class="grid gap-3"><bo-progress :value="25" variant="secondary" size="sm" /><bo-progress :value="50" variant="warning" /><bo-progress :value="80" variant="success" size="lg" /></div>
</ExampleFrame>

## API Reference

| Prop         | Type                                                                  | Default       | Description                      |
| ------------ | --------------------------------------------------------------------- | ------------- | -------------------------------- |
| `id`         | `string`                                                              | Autogenerated | Root id.                         |
| `dataTestId` | `string`                                                              | Autogenerated | Test id.                         |
| `value`      | `number`                                                              | `0`           | Current progress value.          |
| `max`        | `number`                                                              | `100`         | Maximum progress value.          |
| `variant`    | `'primary' \| 'secondary' \| 'destructive' \| 'warning' \| 'success'` | `primary`     | Indicator color.                 |
| `size`       | `'sm' \| 'default' \| 'lg'`                                           | `default`     | Track size.                      |
| `label`      | `string`                                                              | -             | Visible progress label.          |
| `showValue`  | `boolean`                                                             | `false`       | Shows the calculated percentage. |
| `role`       | `HTMLAttributes['role']`                                              | `progressbar` | Progress ARIA role.              |
| `ariaLabel`  | `string`                                                              | -             | Accessible label override.       |

The indicator percentage is rounded to the nearest integer.
