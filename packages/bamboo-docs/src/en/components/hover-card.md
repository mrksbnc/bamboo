# Hover Card

`bo-hover-card` shows content after the trigger is hovered or focused. The trigger and content coordinate delayed opening and closing so the pointer can move between them.

## Basic Usage

Compose `bo-hover-card`, `bo-hover-card-trigger`, and `bo-hover-card-content`.

<ExampleFrame :code="basicExample">
  <bo-hover-card>
    <bo-hover-card-trigger>
      <span class="underline decoration-dotted">Bamboo</span>
    </bo-hover-card-trigger>
    <bo-hover-card-content>
      <bo-text>Manifest-driven Vue components for product interfaces.</bo-text>
    </bo-hover-card-content>
  </bo-hover-card>
</ExampleFrame>

## Placement and Timing

The placement values are `top`, `top-start`, `top-end`, `bottom`, `bottom-start`, `bottom-end`, `left`, `left-start`, `left-end`, `right`, `right-start`, and `right-end`. `open-delay` defaults to `700ms`; `close-delay` defaults to `300ms`.

The component is informational, not a modal dialog. Keep essential actions and information available elsewhere on the page.

## API Reference

### Props (bo-hover-card)

| Prop         | Type                     | Default       | Description                              |
| ------------ | ------------------------ | ------------- | ---------------------------------------- |
| `id`         | `string`                 | Autogenerated | Optional id passed to the root.          |
| `dataTestId` | `string`                 | Autogenerated | Optional test id passed to the root.     |
| `open`       | `boolean`                | `false`       | Visibility state used by `v-model:open`. |
| `placement`  | `BoPopoverPlacement`     | `bottom`      | Position of the content.                 |
| `offset`     | `number`                 | `8`           | Gap from the trigger in pixels.          |
| `openDelay`  | `number`                 | `700`         | Opening delay in milliseconds.           |
| `closeDelay` | `number`                 | `300`         | Closing delay in milliseconds.           |
| `role`       | `HTMLAttributes['role']` | `dialog`      | Role of the content panel.               |

The same positioning props can be supplied to `bo-hover-card-content` to override the parent placement or offset. Its `id` and `dataTestId` identify the teleported panel.

### Events

| Event         | Payload   | Description                            |
| ------------- | --------- | -------------------------------------- |
| `update:open` | `boolean` | Emitted when controlled state changes. |

### Slots

| Component               | Name      | Description                      |
| ----------------------- | --------- | -------------------------------- |
| `bo-hover-card`         | `default` | Trigger and content children.    |
| `bo-hover-card-trigger` | `default` | Hoverable and focusable content. |
| `bo-hover-card-content` | `default` | Information card content.        |
