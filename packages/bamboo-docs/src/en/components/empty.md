# Empty

`bo-empty` provides a consistent empty-state layout with optional media, descriptive text, and an action area.

## Basic Usage

Use `title` and `description` for the generated text. The `media` and `action` slots are optional.

<ExampleFrame :code="basicExample">
  <bo-empty title="No projects yet" description="Create a project to get started.">
    <template #media>
      <bo-icon icon="folder" size="lg" aria-hidden="true" />
    </template>
    <template #action>
      <bo-button>Create project</bo-button>
    </template>
  </bo-empty>
</ExampleFrame>

<ExampleFrame :code="customExample">
  <bo-empty>
    <template #default><strong>Nothing matches this filter.</strong><p>Try a broader search.</p></template>
    <template #action><bo-button variant="outline">Clear filters</bo-button></template>
  </bo-empty>
</ExampleFrame>

## Custom Content

The default slot replaces the generated title and description together. This is useful when the empty state needs richer markup.

## API Reference

### Props

| Prop          | Type                     | Default       | Description                           |
| ------------- | ------------------------ | ------------- | ------------------------------------- |
| `id`          | `string`                 | Autogenerated | Id of the root element.               |
| `dataTestId`  | `string`                 | Autogenerated | Test id of the root element.          |
| `title`       | `string`                 | -             | Generated title text.                 |
| `description` | `string`                 | -             | Generated description text.           |
| `role`        | `HTMLAttributes['role']` | -             | Optional role for the empty state.    |
| `ariaLabel`   | `string`                 | -             | Accessible name for the root element. |

### Slots

| Name      | Description                               |
| --------- | ----------------------------------------- |
| `media`   | Icon, image, or other visual content.     |
| `default` | Replaces generated title and description. |
| `action`  | Primary or secondary empty-state actions. |
