# Card

`bo-card` groups related content with optional header and footer regions. It renders as a `div` and does not impose interaction behavior.

## Basic Usage

Use `title` and `description` for the standard header, the default slot for the body, and `footer` for actions.

<ExampleFrame :code="basicExample">
  <bo-card title="Project settings" description="Manage access and notifications.">
    <p>Card content belongs in the default slot.</p>
    <template #footer>
      <bo-button size="sm">Save changes</bo-button>
    </template>
  </bo-card>
</ExampleFrame>

## Variants

The `variant` controls the accent border. Available values are `default`, `primary`, `secondary`, `destructive`, `warning`, and `success`.

<ExampleFrame :code="variantsExample">
  <div class="grid gap-4 sm:grid-cols-2">
    <bo-card variant="default" title="Default">Neutral card.</bo-card>
    <bo-card variant="primary" title="Primary">Primary accent.</bo-card>
    <bo-card variant="warning" title="Warning">Warning accent.</bo-card>
    <bo-card variant="success" title="Success">Success accent.</bo-card>
  </div>
</ExampleFrame>

## Custom Slots

The `header` slot replaces the generated title and description together. The `footer` slot is omitted from the DOM when it is not provided.

## API Reference

### Props

| Prop          | Type                                                                               | Default       | Description                   |
| ------------- | ---------------------------------------------------------------------------------- | ------------- | ----------------------------- |
| `id`          | `string`                                                                           | Autogenerated | The id of the card.           |
| `dataTestId`  | `string`                                                                           | Autogenerated | The test id of the card.      |
| `variant`     | `'default' \| 'primary' \| 'secondary' \| 'destructive' \| 'warning' \| 'success'` | `default`     | Accent border variant.        |
| `title`       | `string`                                                                           | -             | Header title.                 |
| `description` | `string`                                                                           | -             | Text below the title.         |
| `role`        | `HTMLAttributes['role']`                                                           | -             | Optional role for the card.   |
| `ariaLabel`   | `string`                                                                           | -             | Accessible name for the card. |

### Slots

| Name      | Description                            |
| --------- | -------------------------------------- |
| `header`  | Replaces the generated header content. |
| `default` | Card body content.                     |
| `footer`  | Footer content, usually actions.       |
