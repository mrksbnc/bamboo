# Drawer

`bo-drawer` renders a teleported dialog panel from the left or right side of the viewport. It manages body scrolling while open and focuses the panel.

## Basic Usage

<ExampleFrame :code="rightExample">
  <bo-button @click="open = true">Open drawer</bo-button>
  <bo-drawer v-model:open="open" title="Project details" description="Review the current project.">
    <p>Drawer body content.</p>
    <template #footer><bo-button @click="open = false">Done</bo-button></template>
  </bo-drawer>
</ExampleFrame>

## Side and Size

`side` accepts `left` and `right`; `size` accepts `sm`, `default`, `lg`, and `full`. Backdrop clicks and Escape close the drawer by default.

<ExampleFrame :code="leftExample">
  <bo-button variant="secondary" @click="leftOpen = true">Open left drawer</bo-button>
  <bo-drawer v-model:open="leftOpen" side="left" size="sm" title="Navigation">
    <nav class="grid gap-2"><a href="/">Home</a><a href="/projects">Projects</a></nav>
  </bo-drawer>
</ExampleFrame>

## API Reference

| Prop                                               | Type                                  | Default       | Description                              |
| -------------------------------------------------- | ------------------------------------- | ------------- | ---------------------------------------- |
| `id`                                               | `string`                              | Autogenerated | Panel id.                                |
| `dataTestId`                                       | `string`                              | Autogenerated | Panel test id.                           |
| `open`                                             | `boolean`                             | `false`       | Visibility used by `v-model:open`.       |
| `title`                                            | `string`                              | -             | Generated header title.                  |
| `description`                                      | `string`                              | -             | Generated description.                   |
| `side`                                             | `'left' \| 'right'`                   | `right`       | Panel side.                              |
| `size`                                             | `'sm' \| 'default' \| 'lg' \| 'full'` | `default`     | Panel size.                              |
| `closeOnBackdrop`                                  | `boolean`                             | `true`        | Closes on backdrop click.                |
| `closeOnEscape`                                    | `boolean`                             | `true`        | Closes on Escape.                        |
| `showClose`                                        | `boolean`                             | `true`        | Shows the close button.                  |
| `closeAriaLabel`                                   | `string`                              | `Close`       | Close button label.                      |
| `role`                                             | `HTMLAttributes['role']`              | `dialog`      | Panel ARIA role.                         |
| `ariaLabel` / `ariaLabelledBy` / `ariaDescribedBy` | `string`                              | -             | Accessible name and reference overrides. |

The `default` slot is the body. `header` replaces the generated title header and `footer` renders a footer region. The component emits `update:open` and `close`.
