# Drawer

Use `bo-drawer` for navigation, details, or actions that can remain in a side panel.

## Usage

<ExampleFrame :code="example">
  <bo-button @click="open = true">Open drawer</bo-button>
  <ClientOnly>
    <bo-drawer v-model:open="open" title="Project details" description="Review the current project.">
      <p>Drawer body content.</p>
      <template #footer>
        <bo-button @click="open = false">Done</bo-button>
      </template>
    </bo-drawer>
  </ClientOnly>
</ExampleFrame>

## Shared Drawer State

Use `useDrawer` when a drawer needs to be opened from a component that does not own its template. Mount `bo-drawer-viewport` once in the application shell.

<ExampleFrame :code="managedExample">
  <div class="flex flex-wrap gap-2">
    <bo-button @click="showManagedDrawer({ title: 'Managed drawer', description: 'Opened from the shared composable.' })">Open managed drawer</bo-button>
    <bo-button kind="outline" @click="clearManagedDrawers">Clear drawers</bo-button>
  </div>
  <ClientOnly><bo-drawer-viewport /></ClientOnly>
</ExampleFrame>

## Side and size

Use `side="left"` for navigation and `size="sm"`, `lg`, or `full` for the panel width.

<ExampleFrame :code="leftExample">
  <bo-button variant="secondary" @click="leftOpen = true">Open left drawer</bo-button>
  <ClientOnly>
    <bo-drawer v-model:open="leftOpen" side="left" size="sm" title="Navigation">
      <p>Navigation links.</p>
    </bo-drawer>
  </ClientOnly>
</ExampleFrame>

## API

| Prop / event / slot                                         | Type                          | Default          | Description                               |
| ----------------------------------------------------------- | ----------------------------- | ---------------- | ----------------------------------------- |
| `id` / `dataTestId`                                         | `string`                      | autogenerated    | Panel attributes.                         |
| `open`                                                      | `boolean`                     | `false`          | Visibility used by `v-model:open`.        |
| `side`                                                      | `left \| right`               | `right`          | Panel side.                               |
| `size`                                                      | `sm \| default \| lg \| full` | `default`        | Panel width.                              |
| `title` / `description`                                     | `string`                      | -                | Generated header and body content.        |
| `closeOnBackdrop` / `closeOnEscape`                         | `boolean`                     | `true`           | Close behavior.                           |
| `showClose` / `closeAriaLabel`                              | `boolean` / `string`          | `true` / `Close` | Close button settings.                    |
| `role` / `ariaLabel` / `ariaLabelledBy` / `ariaDescribedBy` | native accessibility types    | `dialog` / -     | Panel semantics.                          |
| `update:open`                                               | event                         | -                | Emitted when the panel state changes.     |
| `close`                                                     | event                         | -                | Emitted when the drawer requests closing. |
| `default` / `header` / `footer`                             | slot                          | -                | Body, header, and footer content.         |
