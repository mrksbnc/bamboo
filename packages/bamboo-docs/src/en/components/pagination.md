# Pagination

Use `bo-pagination` when a collection is split into discrete pages. It calculates the page count from `total` and `page-size`.

## Usage

<ExampleFrame :code="example">
  <div class="grid gap-2">
    <bo-pagination v-model:page="page" :total="42" :page-size="10" />
    <span class="text-sm text-neutral-500">Page {{ page }}</span>
  </div>
</ExampleFrame>

## Siblings

Increase `sibling-count` for more visible pages around the current page.

<ExampleFrame :code="largeExample">
  <div class="grid gap-2">
    <bo-pagination v-model:page="page" :total="240" :page-size="10" :sibling-count="2" />
    <span class="text-sm text-neutral-500">Page {{ page }} of 24</span>
  </div>
</ExampleFrame>

## API

| Prop / event         | Type                       | Default                     | Description                            |
| -------------------- | -------------------------- | --------------------------- | -------------------------------------- |
| `id` / `dataTestId`  | `string`                   | autogenerated               | Navigation attributes.                 |
| `total`              | `number`                   | required                    | Total item count.                      |
| `page`               | `number`                   | `1`                         | Current page used by `v-model:page`.   |
| `pageSize`           | `number`                   | `10`                        | Items per page.                        |
| `siblingCount`       | `number`                   | `1`                         | Pages shown beside the current page.   |
| `disabled`           | `boolean`                  | `false`                     | Disables page controls.                |
| `role` / `ariaLabel` | native accessibility types | `navigation` / `Pagination` | Navigation semantics.                  |
| `update:page`        | event                      | -                           | Emitted when the current page changes. |
