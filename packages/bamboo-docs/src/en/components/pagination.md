# Pagination

`bo-pagination` calculates pages from `total` and `pageSize`, then exposes the current page through `v-model:page`. It renders previous, next, page, and ellipsis items.

## Basic Usage

<ExampleFrame :code="basicExample">
  <div><bo-pagination v-model:page="page" :total="42" :page-size="10" /><p class="mt-2 text-sm text-neutral-500">Page {{ page }}</p></div>
</ExampleFrame>

## Siblings and Large Collections

`siblingCount` controls how many pages appear around the current page. Collections with more than seven pages use ellipses.

<ExampleFrame :code="compactExample">
  <div><bo-pagination v-model:page="page" :total="240" :page-size="10" :sibling-count="2" aria-label="Search results pages" /><p class="mt-2 text-sm text-neutral-500">Page {{ page }} of 24</p></div>
</ExampleFrame>

## API Reference

| Prop           | Type                     | Default       | Description                            |
| -------------- | ------------------------ | ------------- | -------------------------------------- |
| `id`           | `string`                 | Autogenerated | Navigation id.                         |
| `dataTestId`   | `string`                 | Autogenerated | Test id.                               |
| `total`        | `number`                 | Required      | Total item count.                      |
| `page`         | `number`                 | `1`           | Current page used by `v-model:page`.   |
| `pageSize`     | `number`                 | `10`          | Items represented by one page.         |
| `siblingCount` | `number`                 | `1`           | Visible pages beside the current page. |
| `disabled`     | `boolean`                | `false`       | Disables page controls.                |
| `role`         | `HTMLAttributes['role']` | `navigation`  | Navigation role.                       |
| `ariaLabel`    | `string`                 | `Pagination`  | Accessible navigation label.           |

The component emits `update:page`. Page numbers are clamped by the rendered controls to the calculated page range.
