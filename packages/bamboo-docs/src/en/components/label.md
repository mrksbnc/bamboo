# Label

`bo-label` renders a native `label` element and forwards its `for` relationship to the associated control. The required marker is decorative and does not replace native validation.

## Association

<ExampleFrame :code="basicExample">
  <div class="grid gap-2"><bo-label for="email">Email address</bo-label><input id="email" class="rounded border px-3 py-2" /></div>
</ExampleFrame>

## Sizes and States

<ExampleFrame :code="statesExample">
  <div class="grid gap-3"><bo-label size="sm">Small label</bo-label><bo-label size="lg" required>Required field</bo-label><bo-label disabled>Disabled field</bo-label></div>
</ExampleFrame>

## API Reference

| Prop         | Type                        | Default       | Description                        |
| ------------ | --------------------------- | ------------- | ---------------------------------- |
| `id`         | `string`                    | Autogenerated | Label id.                          |
| `dataTestId` | `string`                    | Autogenerated | Test id.                           |
| `for`        | `string`                    | -             | Id of the associated form control. |
| `required`   | `boolean`                   | `false`       | Shows the required marker.         |
| `disabled`   | `boolean`                   | `false`       | Applies disabled label styling.    |
| `size`       | `'sm' \| 'default' \| 'lg'` | `default`     | Label size.                        |
| `role`       | `HTMLAttributes['role']`    | -             | Optional role.                     |
| `ariaLabel`  | `string`                    | -             | Accessible label value.            |

The default slot contains the label text or custom label content.
