# Scroll Area

`bo-scroll-area` wraps content in a focusable viewport and displays custom scrollbars while the pointer is over overflowing content. Set `maxHeight` in pixels to constrain the viewport.

## Vertical Scrolling

<ExampleFrame :code="basicExample">
  <bo-scroll-area :max-height="160" aria-label="Notifications"><div class="grid gap-2 p-3"> <p v-for="item in content" :key="item">{{ item }}</p></div></bo-scroll-area>
</ExampleFrame>

## Masked and Horizontal Content

`masked` applies the masked scroll-area style. The viewport supports both vertical and horizontal overflow.

<ExampleFrame :code="maskedExample">
  <bo-scroll-area :max-height="120" masked aria-label="Long content"><div class="min-w-[36rem] p-3">This region also scrolls horizontally when its content is wider than the viewport.</div></bo-scroll-area>
</ExampleFrame>

## API Reference

| Prop         | Type      | Default       | Description                                |
| ------------ | --------- | ------------- | ------------------------------------------ |
| `id`         | `string`  | Autogenerated | Root id.                                   |
| `dataTestId` | `string`  | Autogenerated | Test id.                                   |
| `maxHeight`  | `number`  | -             | Maximum viewport height in pixels.         |
| `masked`     | `boolean` | `false`       | Applies masked styling.                    |
| `ariaLabel`  | `string`  | -             | Adds a `region` role and accessible label. |

The default slot contains the scrollable content. The viewport is focusable with `tabindex="0"`.
