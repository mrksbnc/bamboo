# Scroll Area

Use `bo-scroll-area` when content needs a bounded viewport with custom scrollbars.

## Usage

<ExampleFrame :code="basicExample">
  <bo-scroll-area :max-height="160" class="max-w-sm" aria-label="Notifications">
    <div class="grid gap-2 p-3">
      <p v-for="item in items" :key="item">{{ item }}</p>
    </div>
  </bo-scroll-area>
</ExampleFrame>

## Horizontal content

Set `masked` for the masked style. The viewport supports both vertical and horizontal overflow.

<ExampleFrame :code="horizontalExample">
  <bo-scroll-area :max-height="120" masked aria-label="Wide content">
    <div class="min-w-[36rem] p-3">Content wider than the viewport.</div>
  </bo-scroll-area>
</ExampleFrame>

## API

| Prop / slot         | Type      | Default       | Description                                           |
| ------------------- | --------- | ------------- | ----------------------------------------------------- |
| `id` / `dataTestId` | `string`  | autogenerated | Root attributes.                                      |
| `maxHeight`         | `number`  | -             | Maximum viewport height in pixels.                    |
| `masked`            | `boolean` | `false`       | Applies the masked style.                             |
| `ariaLabel`         | `string`  | -             | Gives the region an accessible label and region role. |
| `default`           | slot      | -             | Scrollable content.                                   |
