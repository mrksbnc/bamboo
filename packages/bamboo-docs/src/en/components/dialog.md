# Dialog

`bo-dialog` renders a modal panel through a body teleport. It focuses the panel when opened and restores body scrolling when closed.

## Basic Usage

Control the panel with `v-model:open`. The default slot is the body; use `header` and `footer` for complete layout control.

<ExampleFrame :code="basicExample">
  <bo-button @click="open = true">Open dialog</bo-button>
  <bo-dialog v-model:open="open" title="Edit profile" description="Update your public details.">
    <p>Dialog body content.</p>
    <template #footer>
      <bo-button variant="secondary" @click="open = false">Cancel</bo-button>
      <bo-button @click="open = false">Save</bo-button>
    </template>
  </bo-dialog>
</ExampleFrame>

<ExampleFrame :code="detailsExample">
  <bo-button variant="outline" @click="detailsOpen = true">View release details</bo-button>
  <bo-dialog v-model:open="detailsOpen" size="lg" title="Release details">
    <p>Review the changes before publishing.</p>
  </bo-dialog>
</ExampleFrame>

## Sizes and Closing

`size` accepts `sm`, `default`, `lg`, `xl`, and `full`. Backdrop clicks and Escape close the dialog by default; disable either behavior with `close-on-backdrop` or `close-on-escape`. Set `show-close` to `false` to hide the header close button.

## Accessibility

The panel uses `role="dialog"`, `aria-modal="true"`, and derives labelled and described references from `title` and `description`. Supply the ARIA reference props when using custom header content without a title.

## API Reference

### Props

| Prop              | Type                                          | Default       | Description                              |
| ----------------- | --------------------------------------------- | ------------- | ---------------------------------------- |
| `id`              | `string`                                      | Autogenerated | Id of the dialog panel.                  |
| `dataTestId`      | `string`                                      | Autogenerated | Test id of the dialog panel.             |
| `open`            | `boolean`                                     | `false`       | Visibility state used by `v-model:open`. |
| `title`           | `string`                                      | -             | Generated header title.                  |
| `description`     | `string`                                      | -             | Generated body description.              |
| `size`            | `'sm' \| 'default' \| 'lg' \| 'xl' \| 'full'` | `default`     | Panel size.                              |
| `closeOnBackdrop` | `boolean`                                     | `true`        | Closes when the backdrop is clicked.     |
| `closeOnEscape`   | `boolean`                                     | `true`        | Closes when Escape is pressed.           |
| `showClose`       | `boolean`                                     | `true`        | Shows the header close button.           |
| `closeAriaLabel`  | `string`                                      | `Close`       | Accessible close-button label.           |
| `role`            | `HTMLAttributes['role']`                      | `dialog`      | ARIA role of the panel.                  |
| `ariaLabel`       | `string`                                      | -             | Accessible name override.                |
| `ariaLabelledBy`  | `string`                                      | -             | Id of an external labelling element.     |
| `ariaDescribedBy` | `string`                                      | -             | Id of an external description element.   |

### Events

| Event         | Payload   | Description                      |
| ------------- | --------- | -------------------------------- |
| `update:open` | `boolean` | Emitted when visibility changes. |
| `close`       | -         | Emitted when the dialog closes.  |

### Slots

| Name      | Description                             |
| --------- | --------------------------------------- |
| `default` | Dialog body content.                    |
| `header`  | Replaces the generated title header.    |
| `footer`  | Footer content, usually action buttons. |
