# Chart

`bo-chart` renders common line, area, bar, pie, and donut charts without a charting runtime dependency. It uses responsive SVG and keeps the data model consistent across chart types.

## Line and Area

Pass category names through `labels` and one or more named series through `series`. Area charts use the same data model as line charts.

<ExampleFrame :code="lineExample">
  <BoChart
    type="line"
    :labels="['Jan', 'Feb', 'Mar', 'Apr']"
    :series="[{ name: 'Revenue', data: [18, 26, 22, 34] }]"
    title="Monthly revenue"
  />
</ExampleFrame>

<ExampleFrame :code="comparisonExample">
  <BoChart
    type="bar"
    :labels="['Q1', 'Q2', 'Q3', 'Q4']"
    :series="[
      { name: 'Current year', data: [42, 58, 64, 78] },
      { name: 'Previous year', data: [36, 49, 57, 63] }
    ]"
    title="Quarterly comparison"
  />
</ExampleFrame>

## Pie and Donut

Pie and donut charts use the first series and map each value to the corresponding label. Use them for part-to-whole relationships with a small number of categories.

<ExampleFrame :code="shareExample">
  <BoChart
    type="donut"
    :labels="['Desktop', 'Mobile', 'Tablet']"
    :series="[{ name: 'Traffic', data: [58, 32, 10] }]"
    title="Traffic sources"
  />
</ExampleFrame>

## Accessibility

The chart has an image role, an accessible label, and a visually hidden summary. Keep `aria-label` specific when the chart title does not fully describe the data. Legends are visual support; include the important values in nearby text when exact values matter.

## API Reference

### Props

| Prop         | Type                                            | Default       | Description                                    |
| ------------ | ----------------------------------------------- | ------------- | ---------------------------------------------- |
| `id`         | `string`                                        | Autogenerated | Root element id.                               |
| `dataTestId` | `string`                                        | Autogenerated | Test id attribute.                             |
| `type`       | `'line' \| 'area' \| 'bar' \| 'pie' \| 'donut'` | `'line'`      | Visualization type.                            |
| `title`      | `string`                                        | -             | Optional visible chart title.                  |
| `labels`     | `string[]`                                      | `[]`          | Category labels.                               |
| `series`     | `BoChartSeries[]`                               | `[]`          | Named numeric series.                          |
| `height`     | `number`                                        | `320`         | SVG height in pixels, with a minimum of `180`. |
| `showLegend` | `boolean`                                       | `true`        | Shows the visual legend.                       |
| `showGrid`   | `boolean`                                       | `true`        | Shows Cartesian grid lines.                    |
| `stacked`    | `boolean`                                       | `false`       | Stacks bar series instead of grouping them.    |
| `ariaLabel`  | `string`                                        | Chart type    | Accessible name override.                      |
