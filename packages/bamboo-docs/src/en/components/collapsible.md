# Collapsible

`bo-collapsible` provides one trigger and one content region. Unlike `bo-accordion`, it has no item collection and can be used independently.

## Basic Usage

Use `v-model:open` for controlled visibility or set `open` through the model initially.

<ExampleFrame :code="basicExample">
  <bo-collapsible v-model:open="open" label="Account details">
    <p>Additional account information is visible here.</p>
  </bo-collapsible>
</ExampleFrame>

## Custom Trigger and Disabled State

Use the `trigger` slot to replace the label. `disabled` prevents toggling and keeps the current state unchanged.

## Accessibility

The trigger exposes `aria-expanded` and `aria-controls`. The content region is kept in the DOM with `aria-hidden` and `v-show`; set `role` when a more specific content-region role is needed.

## API Reference

### Props

| Prop         | Type                     | Default       | Description                              |
| ------------ | ------------------------ | ------------- | ---------------------------------------- |
| `id`         | `string`                 | Autogenerated | Id of the root element.                  |
| `dataTestId` | `string`                 | Autogenerated | Test id of the root element.             |
| `open`       | `boolean`                | `false`       | Visibility state used by `v-model:open`. |
| `label`      | `string`                 | -             | Default trigger text.                    |
| `disabled`   | `boolean`                | `false`       | Prevents opening and closing.            |
| `role`       | `HTMLAttributes['role']` | -             | Role for the content region.             |
| `ariaLabel`  | `string`                 | -             | Accessible label for the trigger.        |

### Events

| Event         | Payload   | Description                      |
| ------------- | --------- | -------------------------------- |
| `update:open` | `boolean` | Emitted when the region toggles. |

### Slots

| Name      | Description                 |
| --------- | --------------------------- |
| `trigger` | Custom trigger content.     |
| `default` | Collapsible content region. |
