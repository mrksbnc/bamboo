# Collapsible

Use `bo-collapsible` for one independent disclosure. Use [`Accordion`](./accordion) for a collection of items.

## Usage

<ExampleFrame :code="basicExample">
  <bo-collapsible v-model:open="open" label="Account details">
    <p>Additional account information.</p>
  </bo-collapsible>
</ExampleFrame>

## Custom trigger

Replace the default label with the `trigger` slot. Use `disabled` to prevent toggling.

<ExampleFrame :code="customExample">
  <bo-collapsible v-model:open="open">
    <template #trigger>Advanced settings</template>
    <p>Optional settings.</p>
  </bo-collapsible>
</ExampleFrame>

## API

| Prop / event / slot  | Type      | Default       | Description                        |
| -------------------- | --------- | ------------- | ---------------------------------- |
| `id` / `dataTestId`  | `string`  | autogenerated | Root attributes.                   |
| `open`               | `boolean` | `false`       | Visibility used by `v-model:open`. |
| `label`              | `string`  | -             | Default trigger text.              |
| `disabled`           | `boolean` | `false`       | Prevents toggling.                 |
| `role` / `ariaLabel` | `string`  | `region` / -  | Content and trigger semantics.     |
| `update:open`        | event     | -             | Emitted when visibility changes.   |
| `trigger`            | slot      | -             | Custom trigger content.            |
| `default`            | slot      | -             | Collapsible content.               |
