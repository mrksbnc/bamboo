# Breadcrumb

`bo-breadcrumb` renders an ordered navigation trail. Every item except the last can be a link; the last item is always rendered as the current page.

## Basic Usage

Pass an ordered `items` array. The last item is marked with `aria-current="page"` and is not linked, even if it has an `href`.

<ExampleFrame :code="basicExample">
  <bo-breadcrumb :items="breadcrumbItems" />
</ExampleFrame>

## Icons and Separators

Each item can include an `icon` from Bamboo's icon registry. Set `separator` to change the text between items.

<ExampleFrame :code="customExample">
  <bo-breadcrumb
    :items="[
      { label: 'Home', href: '/', icon: 'home' },
      { label: 'Settings', href: '/settings' },
      { label: 'Profile' },
    ]"
    separator="/"
  />
</ExampleFrame>

## Accessibility

The component renders a `nav` landmark and labels it `Breadcrumb` by default. Use `aria-label` when the page contains more than one navigation landmark or when a different label is more appropriate.

## API Reference

### Props

| Prop         | Type                     | Default       | Description                                  |
| ------------ | ------------------------ | ------------- | -------------------------------------------- |
| `id`         | `string`                 | Autogenerated | The id of the navigation element.            |
| `dataTestId` | `string`                 | Autogenerated | The test id of the navigation element.       |
| `items`      | `BoBreadcrumbItem[]`     | Required      | Items in display order.                      |
| `separator`  | `string`                 | `/`           | Text rendered between items.                 |
| `role`       | `HTMLAttributes['role']` | -             | Optional role for the navigation element.    |
| `ariaLabel`  | `string`                 | `Breadcrumb`  | Accessible name for the navigation landmark. |

### `BoBreadcrumbItem`

| Property | Type     | Description                              |
| -------- | -------- | ---------------------------------------- |
| `label`  | `string` | Visible item label.                      |
| `href`   | `string` | Link destination for non-current items.  |
| `icon`   | `Icon`   | Optional icon rendered before the label. |
