# Components

The following component families are currently exported by `@mrksbnc/bamboo-vue`. Compound primitives are documented together where they share one interaction model.

| Component                                 | Description                                                    |
| ----------------------------------------- | -------------------------------------------------------------- |
| [`bo-accordion`](./accordion)             | Single or multiple expandable sections.                        |
| [`bo-alert-dialog`](./alert-dialog)       | Confirmation surface for important or destructive actions.     |
| [`bo-aspect-ratio`](./aspect-ratio)       | Container that preserves a configurable aspect ratio.          |
| [`bo-avatar`](./avatar)                   | User image, initials, indicator, size, and shape presentation. |
| [`bo-badge`](./badge)                     | Compact status, tag, and label treatment.                      |
| [`bo-breadcrumb`](./breadcrumb)           | Hierarchical navigation trail.                                 |
| [`bo-button`](./button)                   | Actions and form submission controls.                          |
| [`bo-button-group`](./button-group)       | Grouped buttons with orientation and selection state.          |
| [`bo-calendar`](./calendar)               | Month grid with date selection and constraints.                |
| [`bo-carousel`](./carousel)               | Controlled responsive content carousel.                        |
| [`bo-card`](./card)                       | Header, content, media, and footer surface.                    |
| [`bo-checkbox`](./checkbox)               | Boolean input with label and helper states.                    |
| [`bo-collapsible`](./collapsible)         | Disclosure control for showing and hiding content.             |
| [`bo-context-menu`](./context-menu)       | Pointer and keyboard context menu.                             |
| [`bo-date-picker`](./date-picker)         | Single date, range calendar, and range picker primitives.      |
| [`bo-dialog`](./dialog)                   | Modal dialog surface.                                          |
| [`bo-drawer`](./drawer)                   | Responsive side or bottom overlay surface.                     |
| [`bo-dropdown`](./dropdown)               | Action menu with groups, separators, and destructive items.    |
| [`bo-dropzone`](./dropzone)               | Drag-and-drop file selection.                                  |
| [`bo-empty`](./empty)                     | Empty-state layout with media and actions.                     |
| [`bo-file-input`](./file-input)           | Native file selection with validation and file rows.           |
| [`bo-form`](./form)                       | Form and form-field primitives.                                |
| [`bo-icon`](./icon)                       | SVG icon with size and color support.                          |
| [`bo-input`](./input)                     | Text, password, email, and other native input types.           |
| [`bo-input-otp`](./input-otp)             | Segmented one-time-password input.                             |
| [`bo-label`](./label)                     | Form control label.                                            |
| [`bo-loading-pulse`](./loading-pulse)     | Compact pulsing loading indicator.                             |
| [`bo-loading-spinner`](./loading-spinner) | Rotating loading indicator.                                    |
| [`bo-menubar`](./menubar)                 | Horizontal menu bar with keyboard navigation.                  |
| [`bo-marker`](./marker)                   | Small visual status marker.                                    |
| [`bo-modal`](./modal)                     | Imperative or declarative modal overlay.                       |
| [`bo-navbar`](./navbar)                   | Top-to-bottom responsive navigation shell.                     |
| [`bo-number-field`](./number-field)       | Numeric input with increment and decrement controls.           |
| [`bo-pagination`](./pagination)           | Page navigation control.                                       |
| [`bo-popover`](./popover)                 | Positioned arbitrary content surface.                          |
| [`bo-progress`](./progress)               | Determinate progress indicator.                                |
| [`bo-radio-group`](./radio-group)         | Single-choice radio group.                                     |
| [`bo-resizable`](./resizable)             | Resizable panel layout.                                        |
| [`bo-scroll-area`](./scroll-area)         | Scrollable content region.                                     |
| [`bo-separator`](./separator)             | Visual or semantic content separator.                          |
| [`bo-skeleton`](./skeleton)               | Loading placeholder surface.                                   |
| [`bo-slider`](./slider)                   | Keyboard-accessible range slider.                              |
| [`bo-switch`](./switch)                   | Boolean switch control.                                        |
| [`bo-tabs`](./tabs)                       | Keyboard-accessible tablist and panels.                        |
| [`bo-tags-input`](./tags-input)           | Multiple token entry control.                                  |
| [`bo-text`](./text)                       | Typography primitive.                                          |
| [`bo-textarea`](./textarea)               | Multi-line text input.                                         |
| [`bo-toast`](./toast)                     | Temporary feedback notification.                               |
| [`bo-toggle`](./toggle)                   | Single pressed/unpressed action toggle.                        |
| [`bo-toggle-group`](./toggle-group)       | Single or multiple toggle selection.                           |
| [`bo-tooltip`](./tooltip)                 | Contextual popup description.                                  |
| [`bo-visually-hidden`](./visually-hidden) | Visually hidden accessible content.                            |
